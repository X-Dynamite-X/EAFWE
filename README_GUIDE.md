## 🔑 الكلمات المفتاحية

- **التثبيت:** `php artisan migrate`
- **الخطوات:** `خطوة`
- **الأمثلة:** `مثال`
- **المشاكل:** `مشكلة` أو `خطأ`
- **الملفات:** `📄` أو `app/Models/`
- **الأوامر:** `php artisan` أو `$`
